**Nippon Data Atlas** is an original static site that presents Japan's official statistics in one place — population, the economy, society and energy, and the prefectures, from Tokyo to Tottori. Every figure is rendered as a chart or table that carries its source and reference year, so the data stays transparent and traceable.

The site is organised into five sections: an **Overview** with headline indicators, **Population** covering demographic trends, **Economy** with national accounts and market data, **Society & Energy** covering living standards and the energy mix, and **Regions**, which lets you explore each prefecture's profile. The figures are drawn from Japanese official sources including the Statistics Bureau of Japan, the Cabinet Office and the Ministry of Finance.

Everything is plain HTML, CSS and JavaScript served as static files — no build step, no frameworks, and no network requests at runtime, so it works offline and loads instantly on desktop and phone alike.

## Run it

```sh
node serve.ts  (then open http://localhost:8080)
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
